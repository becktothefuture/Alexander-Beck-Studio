# About Me narrative direction

This folder contains the current narrative source for the `beck.fyi` About Me page.

## Current source of truth

`ABOUT-NARRATIVE-SCRIPT-v24.md` is the current editable prose script.

`ABOUT-NARRATIVE-SCRIPT-v24.md` is the approved clean narrative. The canonical content configuration and implementation files define its current visual allocation and global-track story beats.

The current production route still uses the legacy section model while the lab migrates to independently authored Camera, World, Text and Interaction tracks. V24 is written for the target continuous journey: World starts are visual anchors, not containers for the narrative.

The experience is implemented by:

- `react-app/app/src/routes/about/AboutRoute.jsx`;
- `react-app/app/src/routes/about-narrative-lab/`.

The production route and narrative lab share the same current experience. The lab adds controls for refinement; it is not a competing version.
