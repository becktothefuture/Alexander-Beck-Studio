## Recommended direction

Build a living editorial profile rather than a scrolling CV. Typography carries the professional narrative; the point-cloud system provides connective transitions; selected side projects and artefacts provide proof and personality. Keep the core story to roughly 175–220 words and make native vertical scroll the only required interaction.
