## 4. First editorial block

### Introduction

Hi, I’m Alex. I have lived across cultures, which made me curious about how ideas can be understood in different ways. That curiosity led me to Communication Design.

### Career

I’ve worked in agencies, startups and independently. At Dennerlein, I collaborated with developers on interfaces, icon systems and motion. That got me thinking about what screens did, not only how they looked. At Yoti, identity verification made product, brand and trust part of the same problem.

### Connected practice

Those projects taught me to look at product, brand and implementation together. Not because every project needs everything, but because a decision in one place often changes what is possible somewhere else.

## 7. Second editorial block

### Working method

I start by talking to the people closest to the problem and checking the brief’s assumptions. Then I make something—a sketch, prototype, motion study or code—for everyone to react to.

### Collaboration

I often help set the direction, but I do it in the open: sharing work early, explaining my choices and leaving room for other people to improve it.

### Implementation

On a financial index-building project, complexity had to be layered rather than hidden. Some interaction nuance was lost in the build. Since then, I’ve stayed more closely involved through delivery.
