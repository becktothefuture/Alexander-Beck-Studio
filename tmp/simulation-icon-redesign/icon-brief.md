# Simulation Focus Icon Brief

## System
- Canvas: 48 x 48 viewBox, rendered in a 48px modal slot.
- Color: `currentColor` only.
- Stroke: 2.4px, round caps and joins, non-scaling stroke.
- Fill: only solid `currentColor` circles/closed shapes where they clarify material.
- Forbidden SVG features: opacity, grey, masks, clip paths, gradients, filters, url refs.
- Style target: quiet precise UI symbols, not pictorial illustrations.
- Small sizes: must still read at 32px and 24px.

## Rejection Checklist
- No icon depends on grey or opacity for meaning.
- No icon uses masks, clipping, gradients, or filters.
- No face-like two-eyes-and-mouth composition.
- No random unstructured dot clusters.
- No aircraft-like silhouette.
- No knot-like decorative tangle.
