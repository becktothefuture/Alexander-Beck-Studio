# Shared Shell Consolidation Program

This packet makes the React studio shell the only owner of persistent production-route material, chrome, theme, configuration, entry boot, and route metadata.

## Scope

- Home, Portfolio, About, Contact, and their supported direct HTML entries.
- Daily Focus only where it is rendered through the production shell.
- Aggressive removal of legacy shell bootstraps where React owns an equivalent.
- All existing worktree changes are part of the final release and must pass the same gates.

## Non-goals

- Rebuilding simulations or Portfolio physics.
- Redesigning route content.
- Migrating labs, archived demos, or intentionally standalone tools.
- Changing the approved frame, wall, footer, Button Bar, or motion language.

## Completion contract

All PRDs must be actioned in dependency order, verified, moved to `archive/actioned/`, and represented accurately in `progress-log.md`. The production preview must pass route, transition, canvas, Portfolio-gate, theme, shell, and performance checks plus Playwright visual inspection.
